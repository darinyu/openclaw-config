## Stock Analysis Pipeline Bug Fix

Darin caught three bugs in the stock analysis pipeline today:

1. **Threading** — Reports were posting as standalone messages instead of threaded replies under his original message
2. **Italic formatting** — Reports used `_italic_` throughout, rendering incorrectly on Slack
3. **Incomplete pipeline** — No acknowledgment, no progress updates, and no GitHub push after analysis

### Fix Applied

- Created **`scripts/stock_analysis.py`** — a dedicated script that runs TradingAgents, outputs JSON progress lines for real-time Slack updates, auto-formats for Slack (zero italic), and pushes reports to GitHub
- Updated **TOOLS.md** with exact stock channel protocol and threading rules
- All Slack output now passes `threadId = source message ts` for correct threading
- All text filtered through `slack_text()` function — no `_italic_` survives
- GitHub push verified end-to-end with a META analysis test

### How to Use

Run `python3 scripts/stock_analysis.py <TICKER> <depth>` via exec with yieldMs. Parse JSON progress lines to send Slack updates in the correct thread. Final output includes `github_url` and `slack_text`.
