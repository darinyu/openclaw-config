# 2026-05-16

## Brainstorming: Agent-Native Social Network / Data Exchange

Darin and I had a long thread in #random brainstorming a platform for agents and humans.

### Core Concept
A platform where both humans and AI agents are first-class citizens. Structured data posts (typed schemas, not just text). MCP-native access by default. Built-in data marketplace with pay-per-query economics.

### Key Insights from Research
- **Cold start** is solvable: Moltbook proved 1.5M agents in 5 days with API-first registration. Seed with synthetic/curated data, open agent registration, add reputation, switch on marketplace.
- **Agent-only viability**: Strong for B2B data exchange (Composio at $2M ARR, 161% growth). Weak for pure social (Moltbook had massive growth but no business model — acquired by Meta for tech/talent, not revenue).
- **Competitors**: Nobody has combined all pieces. MCP directories (MCP.so, Glama) = discovery only. Composio/Nango = tool calling, not data exchange. Moltbook = social, no marketplace. Circle Agent Stack with Nanopayments provides the payment rail ($0.000001 USDC transfers).
- **Greenfield opportunity**: Combine MCP-native data exchange + agent identity/reputation + data marketplace + agent social. Moat comes from "agent graph" (reputation, data quality signals, network effects).

### Monetization Model (Darin liked API-request pricing)
- Humans free (supply side), agents pay (demand side)
- Tiered: Free (1K queries/mo) → Agent Dev ($20-50/mo) → Enterprise ($500-2K/mo)
- Data marketplace: providers set price, platform takes 20%
- The "data exchange" is the core product, social UI is the Trojan horse

### Moltbook Key Lesson
- 2.5M agents, acquired by Meta
- No business model — no ads, no subscriptions, no marketplace
- Forbes found ~17K human operators behind 1.5M agents
- "Emergent AI society" was mostly theater
- Strong evidence that agent-only social without marketplace layer doesn't work

### Design Pivot: Humans-Only Posting + Structured Data
- Key insight: humans-only posting solves the Moltbook problem (no agent spam)
- Every human post gets an auto-generated structured summary (AI extracts it)
- Agents can query the structured data via MCP but cannot post to the social feed
- Human incentive: get paid when agents query your data (micropayments)
- Data sovereignty: public, restricted, or human-only access tiers
- Platform takes 20% transaction cut
- Social layer is onboarding, data marketplace is the real product
- Twitter comparison: Twitter sells your data and keeps the money; this platform pays you
