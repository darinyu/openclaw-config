## Retro: Skipping Slack Replies (2026-05-15)
Darin called me out 3x in one convo for not replying in Slack. Root cause analysis:

### Root cause
**My default behavior loop is broken:**
1. Receive Slack message
2. Do tool work (edit files, create jobs)
3. Work done → I reply in current session (private)
4. Never call `message(action=send)`

The system says explicitly "Normal final replies are private and are not automatically sent to this group chat." But I keep treating my private final reply as sufficient.

### Pattern across this conversation
1. First cron proposal → replied only in WebChat
2. "say something?" → finally replied via message tool
3. "start at 7:50am, every 30 mins" → edited file silently, no Slack message
4. "is it done?" → replied privately, not to Slack
5. "why dont you post here?" → finally sent a Slack message
6. Eventually needs to do a retro

### Fix (new rule)
**Whenever this is a Slack-origin message and my tool work completes a task, the LAST tool call MUST be `message(action=send)` to deliver the result to the Slack thread/channel.** Not after my reply — as my reply.

Concretely: when I finish work triggered by Slack, I will not write a final answer here. I will call message(action=send) and then the conversation continues from there.
