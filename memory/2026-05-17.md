   - Memory Dreaming: delivery set to #audit (system-managed, exempt from output rule)
   - Tech + Finance: already had bold-only, added output requirement
   - Daily Weather Brief: added bold-only formatting instruction

**Bug fix in slack_formatter.py:** The underscore regex `_text_` was using `(?<!_)_(?!_)` which didn't prevent matching inside words like `NO_REPLY`. When a chunk contained both `NO_REPLY` and `_italic_`, the regex would cross text from the `_` in `NO_REPLY` to the `_` in `_italic_`. Fixed by adding word-boundary guards `(?<!\w)` and `(?!\w)` — the opening `_` must not be preceded by a word char, and the closing `_` must not be followed by a word char. This correctly handles `NO_REPLY` (preserved) vs `_italic_` (converted to bold).
