## 🔴 Lesson: Slack Thread + Italic Rules (Darin called me out)

Darin noticed two repeated failures in #audit:

1. **Thread routing fail** — His @-mention (standalone message, not in a thread) got a top-level channel post as reply instead of a threaded reply under his message. The rule in TOOLS.md says: *Direct @-mention/tag of DDDD → reply in a thread under that message (use the message's ts as threadId).*

2. **Italic in messages** — My audit reply used `_underscore_italic_` formatting throughout, which is a hard rule violation. The slack_format.sh only caught `*asterisk italic*` but not `_underscore italic_.`

**Fix applied:** Updated `scripts/slack_format.sh` to also convert `_underscore_italic_` → `**bold**`.

**Fix applied (global):** Created `scripts/slack_formatter.py` — a Python script that handles BOTH `*italic*` and `_italic_` → `**bold**`, preserving code spans/blocks. `scripts/slack_format.sh` is now a wrapper around it. This is the **single mandatory filter** for ALL Slack output (channel, DM, thread, cron).

**Remember:** Never write `_italic_` or `*italic*` in messages. Always pipe through `scripts/slack_format.sh` before any `message(action=send)` call. Write to `/tmp/slack_msg.txt` first, run the filter, then send the filtered output.
